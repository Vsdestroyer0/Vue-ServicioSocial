Vista inicial de la aplicación. Tiene un mensaje de bienvenida y texto dummy para mostrar la estructura visual de una página construida con el layout `pageLayout`

## Estructura

La vista utiliza `pageLayout` y completa sus slots nombrados:

- `Titulo`: muestra el encabezado de la página
- `Texto`: contiene el mensaje de bienvenida, el texto de ejemplo y la imagen decorativa

La imagen se muestra mediante el componente `<v-img>` de Vuetify y se centra dentro del contenido
